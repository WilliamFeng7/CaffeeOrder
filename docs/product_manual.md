# 产品需求规格与操作手册 (Product Specification & Manual)

本文档包含完整的 PRD (产品需求) 以及针对 B 端 (管理端) 的深度功能说明与操作手册。

## 1. 需求规格说明书 (PRD)

### 1.1 项目背景与目标
*   **背景**: 高中校园课间休息短（10-15分钟），咖啡厅排队严重。
*   **目标**: 构建一套“线上下单、到店即取”的系统，通过分流点单和高效 KDS (厨房显示系统) 制作，提升出餐效率。

### 1.2 核心业务流程
1.  **学生**: 课间前在教室 iPad 下单 -> 支付成功获号 -> 课间到店 -> 凭号取餐。
2.  **咖啡师**: 收到新单提醒 (KDS) -> 制作 -> 点击完成 -> 学生收到通知。

### 1.3 用户角色
| 角色 | 终端 | 核心权限 |
| :--- | :--- | :--- |
| **学生** | Mobile Web | 浏览菜单、多规格选购、余额支付、订单追踪 |
| **咖啡师** | Admin Web | KDS 接单、制作完成、库存管理 (一键沽清) |
| **管理员** | Admin Web | 用户管理 (充值/改密)、商品管理 (上架/改价/库存)、财务分析 |

## 2. 咖啡师作业终端产品文档 (Barista Interface Manual)

本章节专为**门店咖啡师**与**运营人员**设计，详细拆解了管理端界面的视觉交互与操作逻辑。系统设计遵循 **KDS (厨房显示系统)** 理念，优先保证接单与制作的效率。

### 2.1 界面概览 (UI Overview)
管理端采用 **左侧导航 + 右侧内容** 的响应式布局（适配 iPad 横屏）。

*   **一级导航**:
    *   📊 **Dashboard (运营概览)**: 核心监控屏。
    *   📝 **Order Manager (订单管理)**: 核心作业屏 (KDS)。
    *   ☕ **Product Manager (商品管理)**: 菜单维护。
    *   👥 **User Manager (用户管理)**: 会员与充值。
    *   💰 **Finance (财务分析)**: 资金流水。

---

### 2.2 核心模块详解

#### A. 数字化运营看板 (Dashboard)
**场景**: 店长或咖啡师在闲暇时监控门店健康度。

1.  **全局状态栏**:
    *   显示 "实时数据更新于 HH:MM"，系统每 **2秒** 自动拉取最新数据。
    *   提供 [刷新数据] 按钮，用于网络不稳定时手动重试。

2.  **核心指标卡片 (Key Metrics)**:
    *   **今日营业额**: 显示今日累计实收金额 (¥)，含环比昨日的涨跌幅（如 <span style="color:green">▲12%</span>）。
    *   **当前制作中 (Pending)**: <span style="background:#103E32; color:white; padding:2px 6px; border-radius:4px;">核心关注</span>。深绿色卡片高亮显示。数字代表当前积压的订单数。若此数字超过 **10**，建议立即暂停接单或调配人手。
    *   **客单价 (AOV)**: 监控单笔订单平均金额。

3.  **订单漏斗 (Real-time Funnel)**:
    *   可视化展示订单流转状态：`待接单` -> `制作中` -> `请取餐`。
    *   **智能排队预估**: 系统根据积压单量自动计算 "预计等待时间"（如 <span style="color:orange">预计等待 12 分钟</span>）。若等待时间 > 15分钟，指示灯变红。

4.  **库存预警 (Inventory Alerts)**:
    *   面板右下角自动列出 **库存为 0** 的商品列表。
    *   **操作**: 提示需尽快补货。

#### B. KDS 订单管理系统 (Order Ops)
**场景**: 咖啡师的高频作业界面，替代传统纸质小票。

1.  **筛选器 (Filter Bar)**:
    *   **全部 (All)**: 查看当天所有记录。
    *   **待处理 (Pending)**: <span style="background:#103E32; color:white; padding:2px 6px; border-radius:4px;">默认视图</span>。仅展示状态为 `Created` (已支付) 和 `Processing` (制作中) 的订单。
    *   **已完成 (Completed)**: 查询历史出餐记录。

2.  **订单卡片 (Order Card)**:
    每个订单以一个长条形卡片展示，包含：
    *   **左侧**: 取餐号 (大字号，如 **#2048**)。
        *   <span style="background:#FFFBEB; color:#D97706;">黄色背景</span> = 待制作。
        *   <span style="background:#ECFDF5; color:#059669;">绿色背景</span> = 已完成。
    *   **中部**: 
        *   客户名 (如 "ZhangSan")。
        *   下单时间 (如 "10:24:30")。
        *   订单金额 (¥28.00) 及用餐方式 (堂食/打包)。
    *   **右侧操作区**:
        *   **[完成订单] 按钮**: 深绿色主按钮。点击后，订单立即归档，状态变更为 `Completed`。
        *   **交互反馈**: 按钮点击后会有微缩放动画，防止误触。

3.  **订单详情 (Detail Modal)**:
    点击订单卡片任意空白处，弹出详情模态框：
    *   **商品列表**: 图文展示该单包含的饮品。
    *   **规格高亮**: 
        *   系统自动识别特殊规格（如 `去冰`, `半糖`, `换燕麦奶`），并以 <span style="background:#F3F4F6; color:#374151; padding:2px 4px; border:1px solid #E5E7EB;">灰色胶囊标签</span> 醒目展示，**防止做错**。
    *   **总价**: 显示该单总支付金额。

#### C. 商品内容管理 (CMS)
**场景**: 每日开市前的菜单准备或突发缺货处理。

1.  **商品列表**:
    *   网格状展示所有商品卡片。
    *   **售罄标识**: 库存为 0 的商品，图片自动变灰，并覆盖红色 "Sold Out" 徽章。

2.  **快捷编辑**:
    *   **一键沽清**: 进入编辑页，点击红色的 **[设为售罄]** 按钮，库存立即变为 0，学生端无法下单。
    *   **恢复供应**: 点击绿色的 **[恢复库存]** 按钮，库存重置为 999。
    *   **店长推荐**: 勾选 "Store Manager Recommend"，商品将在学生端首页 Banner 区域展示。

3.  **新建/修改**:
    *   支持上传商品图片 (自动压缩 + 原地预览)。
    *   支持设置分类 (Coffee, Tea, Seasonal)。

#### D. 财务与会员 (Finance & User)
**场景**: 处理充值、退款与日终对账。

1.  **会员充值**:
    *   在【用户管理】列表找到学生 -> 点击 [钱包] 图标。
    *   弹窗选择快捷金额 (¥50, ¥100) 或手动输入。
    *   确认后资金实时到账，并记录操作人 (Admin)。

2.  **异常退款**:
    *   **场景**: 学生下错单或长时间未出餐要求退款。
    *   **操作**: 目前需通过【用户管理】为该学生手动充值退款金额，并在备注中记录 "Order #xxxx Refund"。
    *   *(注: 后续版本将在订单详情页集成一键退款按钮)*。

3.  **流水导出**:
    *   在【财务分析】页面，点击 **[导出]** 按钮。
    *   系统生成 `.csv` 表格，包含：流水号、用户名、交易金额、变动后余额、时间、备注。
    *   支持按 "充值" 和 "消费" 两个维度分别导出。

### 2.3 咖啡师标准作业流程 (SOP)

#### 开市准备 (Opening)
1.  登录 Admin 系统，检查 Dashboard 网络连接是否正常 (无红色报错)。
2.  进入 **Product Manager**，检查今日供应的豆子、牛奶是否充足。
3.  若某原料短缺（如燕麦奶），找到对应商品，点击 **[设为售罄]**。

#### 高峰期接单 (Peak Hour)
1.  保持停留在 **Order Manager** 页面，筛选器选为 **"待处理"**。
2.  **听/看**: 关注新订单卡片滑入。
3.  **读**: 点击卡片看详情，大声核对特殊规格（"一杯拿铁，去冰半糖！"）。
4.  **做**: 制作饮品，打包。
5.  **消**: 点击 **[完成订单]**，卡片消失，叫号取餐。

#### 异常处理 (Exception)
*   **错单/退单**: 记录单号 -> 稍后在 User Manager 中进行退款处理。
*   **网络中断**: Dashboard 出现红色报错 -> 检查 Wi-Fi -> 点击 [刷新] -> 若不行则通过 4G热点连接。

## 3. 学生端功能摘要 (Student Feature Summary)

*   **极简点单**: 首页即菜单，大图展示，减少层级。
*   **智能规格**: 选规格时 (如冷/热)，价格会自动计算（若有加价项）。
*   **排队感知**: 首页顶部或订单页显示 "前方还有 N 单"，缓解等待焦虑。
*   **安全支付**: 支付前校验余额，余额不足提示联系管理员充值。

## 4. 常见问题排查 (Troubleshooting)

*   **Q: 为什么 Dashboard 数据不更新？**
    *   A: 检查右上角网络状态。系统每 2 秒自动轮询，若断网会显示红色错误提示，点击 [重试] 按钮即可。
*   **Q: 图片上传失败？**
    *   A: 确保图片大小不超过 5MB，且格式为 jpg/png/webp。
*   **Q: 如何处理错单退款？**
    *   A: 目前需由管理员在 [用户管理] 页面手动为该学生充值对应金额进行"退款"，并在后台备注原因。
