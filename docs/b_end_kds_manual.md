# B端产品文档：门店作业端 (Store Operations / KDS)

## 1. 产品定位
*   **核心目标**：追求极致的**制作效率**与**准确率**。
*   **适用场景**：吧台iPad或触控大屏，供咖啡师/流水线制作员使用。
*   **设计原则**：**KDS (Kitchen Display System)** 模式。减少干扰，核心操作一步到位，异常情况快速处理。

## 2. 界面布局 (UI Layout)

### 2.1 全局顶栏 (Status Bar)
*   **门店状态**：显示“营业中”或“休息中” (点击可切换，用于临时关店或忙碌挂起)。
*   **网络/打印机状态**：小图标指示连接是否正常。
*   **新单通知 (Banner)**：
    *   **触发条件**：当有新订单生成时。
    *   **样式**：顶部出现醒目颜色（如深绿色）横幅，显示“新订单 #102 来啦！(3杯)”，持续 5 秒后自动收起。能够叠加显示（如“您有 3 个新订单”）。
    *   **交互**：点击横幅可快速滚动定位到最新订单卡片。
    *   **声音配置**：**无声** (根据需求配置：纯视觉提示，避免噪音打扰)。

### 2.2 核心看板区 (Kanban Board)
屏幕主体采用流式卡片布局，核心是 **“制作队列”**。

#### A. 制作队列 (Processing Queue)
*   **排序逻辑**：按**下单时间**正序排列（Time First），最久的订单在最前/最左。
*   **超时预警**：
    *   逻辑：当前时间 - 下单时间 > 10分钟。
    *   表现：卡片边框闪烁红色或变红，卡片顶部显示“超时”红色标签。
*   **订单卡片 (Card UI)**：
    *   **头部**：流水号 (#102 放大显示) | 顾客称呼 | 倒计时/下单时间。
    *   **内容区**：
        *   **商品列表**：大号字体显示商品名（如“拿铁”）。
        *   **规格高亮**：对于定制项（**去冰**、**少糖**、**换燕麦奶**）使用醒目背景色块高亮，防止做错。
    *   **底部操作**：
        *   **【制作完成】按钮** (大尺寸，全宽，易点击)。
        *   *交互逻辑*：点击后 -> 系统后台改变订单状态 -> 触发发送“请取餐”通知给用户 -> **卡片立即消失**（进入历史记录）。

#### B. 异常/挂起区 (Exceptions) - *可选折叠*
*   用于放置“缺货等待联系”或“顾客要求晚点做”的订单，避免阻塞主队列。

### 2.3 快捷功能菜单 (Quick Actions Sidebar)
*   **一键沽清 (Quick Stock)**：点击弹出高频原料面板（牛奶、豆子、杯子），一键切换“有货/售罄”状态，立刻同步到学生端。
*   **历史订单 (History)**：
    *   入口：查看已完成/已取消的订单列表。
    *   功能：支持点击某单后**【补打小票】**（防止打印机卡纸或小票遗失）。
    *   搜索：支持输号查询。

## 3. 关键交互流程

### 3.1 接单与制作流
1.  **进单**：顶部横幅弹出“新订单 #102”，卡片自动插入队列尾部。
2.  **看单**：咖啡师查看卡片，“去冰”、“少糖”高亮显示，一目了然。
3.  **出餐**：制作完毕，打包/装袋。
4.  **完成**：点击卡片底部【制作完成】。UI 上卡片立即移除。用户端收到取餐通知。

### 3.2 异常处理流
*   **缺货/无法制作**：
    *   点击卡片右上角“...” -> 选择【拒单/退款】。
    *   弹窗需二次确认，并简选理由（如“缺料”、“机器故障”）。
    *   系统触发退款并通知用户。
*   **打印故障**：
    *   进入“历史订单” -> 找到该单 -> 点击【重打小票】。
